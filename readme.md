Manasvi Naik's Portfolio (101011805)

This was a personal portfolio website assignment that I built for my Web and Script Programming course. It showcases my background in NITS at Ontario Tech University, as well as some of my technical projects.

This Project was Built With:
Node.js & Express
EJS template
Bootstrap version 5.0
Font Awesome
HTML/CSS

Render Link: https://web-and-script-assignment-2-manasvi-naik.onrender.com

Pages:
Header: This has navigation tabs to all of the pages

Home: This page has an intro and clickable navigation buttons that link to the main sections.

About: This page has some information about me and my program.

Projects: I added 3 projects that I have created through university coursework as well as on my personal time.

Contact: The contact page has a form to send messages to me 

Footer: The links to my GitHub and Linkedin are in the footer.

Folder Structure (I Used AI to create this tree diagram)

├── public/          # CSS and JS (app.js)
├── routes/          # Has the main index.js router
├── views/
│   ├── partials/    # Header, main nav, and footer
│   └── *.ejs        # All of the page templates (index, about, projects, contact)
├── app.js          
└── package.json

Clone the repo:
git clone https://github.com/ManasviNN/Assignment2

Install packages:

npm install

Start the server:

npm start
